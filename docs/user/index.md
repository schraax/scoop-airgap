# User Guide

This guide is for Windows users who want to install and manage software with Scoop in an environment that has no direct internet access.

Your IT or platform team has set up an internal package mirror. You will point Scoop at that mirror instead of the public Scoop buckets — everything else works exactly as described in the standard Scoop documentation.

## Guides in this section

- [Initial Setup](setup.md) — installing Scoop and adding the internal buckets
- [Daily Use](usage.md) — installing, updating, and managing packages
- [Troubleshooting](troubleshooting.md) — what to do when something goes wrong
